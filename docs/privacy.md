# Privacy description

The open-source RFP Builder runtime operates locally. It has no account, analytics, remote AI call, database or automatic contact submission. It receives answers on loopback for document formatting and returns the requested output. It does not persist answers or print them in server logs. Users choose when to export files and where to retain them.

The optional Grail link opens a separate website, whose policy applies to that visit. The link does not contain the brief or other user data. Installing the discovery skill in an AI client does not change that client's own processing, retention or workspace access policies.

This describes the present local implementation. It is not a claim about a future hosted service. Any hosting, telemetry, contact form or remote processing requires an updated policy and explicit disclosure before use. Publisher review and a stable public policy URL are needed for directory submission.
